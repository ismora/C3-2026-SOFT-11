¿Cuándo usar cada etiqueta?

<header>
Encabezado de la página o de una sección. Suele contener el logotipo, título y navegación principal.
<nav>
Bloque de navegación con enlaces principales o secundarios. Debe usarse para conjuntos importantes de enlaces, no para cualquier lista.
<main>
Contenido principal y único del documento. No debe incluir información repetida como barras laterales o publicidad.
<section>
Agrupa contenido temáticamente relacionado. Siempre debe tener un encabezado (por ejemplo <h2> a <h6>).
<article>
Contenido independiente y autocontenido, como una noticia, un comentario o una publicación de blog. Puede tener su propio <header> y <footer>.
<aside>
Contenido indirectamente relacionado con el principal, como barras laterales, notas al margen o publicidad.
<footer>
Pie de página de la página o de una sección. Información de autor, enlaces legales, contacto, etc.

Importante: Mantener una jerarquía lógica de encabezados. No omitir niveles (ej. de <h2> a <h4> sin pasar por <h3>). Usa <h1> solo para el título principal de la página.

Constraste de colores

Garantiza que el texto sea legible para personas con baja visión o daltonismo. Según la WCAG, el contraste entre el texto y su fondo debe ser de al menos 4.5:1 para el texto normal y de 3:1 para el texto grande, para asegurar que el contenido sea legible y fácil de leer.

ARIA (Accessible Rich Internet Applications)

ARIA es un conjunto de atributos que complementan el HTML para hacer que los contenidos web y las aplicaciones sean más accesibles. Se usa cuando el HTML no puede expresar adecuadamente la semántica de componentes complejos.

Diseño responsivo

Crear diseños que se adapten a diferentes tamaños de pantalla y permitan el zoom sin romper la funcionalidad o legibilidad.

Validación y pruebas

Implementar un proceso sistemático de pruebas que combine herramientas automatizadas, verificación manual y testing con usuarios reales.

Usabilidad

La usabilidad se enfoca en la eficiencia, efectividad y satisfacción del usuario al interactuar con una interfaz. Un diseño usable reduce errores, facilita la navegación y hace que las tareas sean intuitivas.

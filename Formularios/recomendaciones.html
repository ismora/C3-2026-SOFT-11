Desarrollo de interfaz de usuario

Formularios

Un formulario es un diálogo con la persona que lo rellena. Si algo va mal, el desarrollar debe decirle qué falló, dónde y cómo arreglarlo (formulario frustrante vs usable).

01 · EL FLUJO

¿Qué ocurre con los datos?

Usuario
Formulario
JavaScript
Servidor

Flujo:

  1. La persona completa el formulario.
  2. JavaScript captura de los datos.
  3. JavaScript valida los datos.
  4. JavaScript brindar retroalimentación para la corrección de errores.
  5. fetch() realiza la petición.
  6. El servidor procesa la información.
  7. El servidor devuelve una respuesta.
  8. JavaScript actualiza la interfaz.
Idea clave: El desarrollador controla el proceso de envío.

02 · HTML

La estructura de un formulario

El elemento <form> agrupa los controles que utilizamos para recopilar información. 

<form id="formularioUsuario" novalidate>

    <label for="nombre">
        Nombre
    </label>

    <input type="text" id="nombre" name="nombre" >

    <label for="correo">
        Correo electrónico
    </label>

    <input type="email" id="correo" name="correo">

    <button type="submit">
        Enviar
    </button>

</form>
<form>
Agrupa el formulario.
<label>
Identifica un campo.
<input>
Recibe información.
<button>
Ejecuta una acción.
<novalidate >
Desactiva la validación nativa del navegador.
HTML define la estructura del formulario. JavaScript controlará posteriormente qué hacer con los datos.

03 · ACCESIBILIDAD

Labels y accesibilidad

Cada campo debe tener una etiqueta que indique claramente qué información debe introducir la persona.

No permitido 

<input
    type="text"
    placeholder="Nombre"
>

El texto del placeholder desaparece cuando comenzamos a escribir.

Recomendado 

<label for="nombre">
    Nombre
</label>

<input
    type="text"
    id="nombre"
    name="nombre"
>

El label permanece asociado al campo.

¿Cómo se relacionan?

El atributo for del label debe coincidir con el id del campo.

for="correo" id="correo"
El placeholder puede proporcionar una ayuda, pero no debe sustituir al label.

04 · BOOTSTRAP

Formularios con Bootstrap

Bootstrap no crea un tipo diferente de formulario, solo proporciona clases CSS que facilitan la presentación y el diseño responsive.

Formulario HTML 

<label for="nombre">
    Nombre
</label>

<input
    type="text"
    id="nombre"
    name="nombre"
>

<button type="submit">
    Guardar
</button>

El mismo formulario con Bootstrap 

<div class="mb-3">

    <label
        for="nombre"
        class="form-label"
    >
        Nombre
    </label>

    <input
        type="text"
        id="nombre"
        name="nombre"
        class="form-control"
    >

</div>

<button
    type="submit"
    class="btn btn-primary"
>
    Guardar
</button>
